Auto · Find and publish

Type a number and it runs the whole job: it pulls that many designs off MakerWorld's licence-filtered listings — only Public Domain, BY and BY-SA can be selected there, so a NoDerivatives or NonCommercial source cannot enter the queue — then for each one downloads the model together with the photographs the original listing already has, opens the publish wizard in your Chrome, fills every field, declares that listing as the source, and publishes. Nothing asks you per item. An item stops itself only on a fact: no downloadable file, fewer than 3 real photos on the source listing, or it is already in the ledger below. No API key and no generated images are involved anywhere.

0 · Find models to remix

Reads MakerWorld's own popularity listings (trending / popular / hottest) in a throwaway headless browser — no login, no tab of yours, nothing downloaded or published. Pick one and it drops straight into step 1 as the remix source. These listings are already filtered to the three licences a remix may use (Public Domain, BY, BY-SA), and the filter is read back off the page before anything is listed: if MakerWorld stops showing exactly those three chips green, this refuses to return a list rather than hand you models we may not publish.

1 · Source design

A remix on MakerWorld must name a source that is already a design on MakerWorld — that is the site's own rule, measured from the Model Origin box. A Thingiverse or Printables model can only go out as an original listing here.

3 · Photographs of your prints

MakerWorld requires at least 3 photos of the model you actually printed, covering 3 views, and says so on the form. The scraped gallery pictures and this pipeline's edited renders are covers, not print photos — so they are never sent here. Pick the files that came off your camera.

4 · Check, then publish

Check reads MakerWorld's measured requirements only — no browser, no tab, no draft. Publish opens the wizard in your own logged-in Chrome, fills it, and stops if any read-back disagrees with what the source licence says.
