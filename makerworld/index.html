Auto · Find and publish

Type a number and it runs the whole job: it pulls that many designs off MakerWorld's licence-filtered listings — only Public Domain, BY and BY-SA can be selected there, so a NoDerivatives or NonCommercial source cannot enter the queue — then for each one downloads the model, draws its own pictures for the listing from that listing's name and description, opens the publish wizard in your Chrome, fills every field, declares that listing as the source, and publishes. Nothing asks you per item, and no photograph from the source listing is attached anywhere. An item stops itself only on a fact: no downloadable file, no category named, a licence the form cannot declare (CC0 included — see the note in card 3), fewer than 3 drawn pictures coming back, or it is already in the ledger below. The pictures come from the free keyless generator: no API key, no account, no money, and it is thin on capacity, so a listing can spend a minute or two waiting on it.

0 · Find models to remix

Reads MakerWorld's own popularity listings (trending / popular / hottest) in a throwaway headless browser — no login, no tab of yours, nothing downloaded or published. Pick one and it drops straight into step 1 as the remix source. These listings are already filtered to the three licences a remix may use (Public Domain, BY, BY-SA), and the filter is read back off the page before anything is listed: if MakerWorld stops showing exactly those three chips green, this refuses to return a list rather than hand you models we may not publish.

1 · Source design

A remix on MakerWorld must name a source that is already a design on MakerWorld — that is the site's own rule, measured from the Model Origin box. A Thingiverse or Printables model can only go out as an original listing here.

2 · Listing

The source's own description is posted unchanged: no added source link, no remix note, no rewritten text. The Find & publish run does the same, automatically.

3 · The listing pictures

Every picture on the listing is drawn here from the model's own name and description, with no words, badges or watermarks in it — and the generator's own corner mark is cut off the bottom of the frame before the file is kept. The other maker's gallery photographs are never attached, and neither are your own. The free generator is thin on capacity: measured on 26 Oct, one picture in about 6 seconds and then a refusal for a minute or two, so a set of five takes up to five minutes. If fewer than 3 come back the publish stops and says so instead of quietly using someone else's photo.

MakerWorld requires at least 3 photos of the model you actually printed, covering 3 views, and says so on the form. The scraped gallery pictures are the other maker's photographs, not yours, and this pipeline's edited renders are covers — neither is sent here. Pick the files that came off your camera.

4 · Check, then publish

Check reads MakerWorld's measured requirements only — no browser, no tab, no draft. Publish opens the wizard in your own logged-in Chrome, fills it, and stops if any read-back disagrees with what the source licence says.
